# AET350C Fall 2026: AudioPixel Live Coding Final Project

Materials for the AET350C final project: a live visual performance built in AET Thunk Machine for the AudioPixel event on Thursday, November 19, 2026, at Payne Theater.

## What's here

- **`Final Prject Plan.pdf`**: the project brief. It covers the event, the checkpoints, what to submit, and how the project is graded.
- **`Student Sample Checkpoint 1/`**: an example of a complete Checkpoint 1 (Assignment 6) submission, inspired by Robert Henke's *CBM 8032 AV*.
  - `student_sample.pdf`: the sample project document
  - `sample_student.json`: the Thunk Machine export
  - `sample_student.mp4`: a short recording of the experiment running with music

Use the sample as a guide to the level of detail expected, not as a project to copy.
